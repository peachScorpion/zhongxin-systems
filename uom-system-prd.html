项目背景与产品定位

Background

集团的制度、规范、协议等标准文件在内部各系统中需要统一、可控地触达给对应角色。本期在 UBK（供应商）、CSP（门店）、UOM（内部运营） 三个内部系统的顶部菜单栏「操作指南」下，新增统一的「标准文件」菜单入口，点击进入各自系统的文件列表页。

产品定位

「标准文件」是嵌入三个内部系统顶部菜单栏的统一文件入口，为各系统用户提供集团标准文件的分类检索、在线预览与下载能力。三系统功能完全一致，仅文件内容与页面标题按系统隔离。

本期仅新增「标准文件」菜单入口及文件列表页，不涉及三个系统原有的首页、工作台、业务模块等其他功能；已有功能保持现状。

业务流程

Process

4.1 菜单入口展示规则（核心规则）

入口展示判定：只有该系统的文件已导入（文件数量 > 0）时，顶部菜单栏「操作指南」下才展示「标准文件」入口；若该系统文件尚未导入（文件数量 = 0），则该入口不展示。
条件菜单入口展示说明
文件数量 > 0展示「操作指南」下拉显示「标准文件」入口，可点击进入列表页
文件数量 = 0不展示入口不展示，用户不可见、不可进入

4.2 进入文件列表页流程

1登录系统→ 2操作指南→ 3标准文件→ 4文件列表页
  • 入口位于顶部菜单栏「操作指南」下拉菜单（「集团制度」分组下，带 NEW 角标）。
  • 点击后新标签页打开对应系统的文件列表页（group-document-center.html?sys=ubk/csp/uom）。

4.3 浏览 / 检索 / 预览 / 下载流程

1进入列表页→ 2分类 Tab / 搜索→ 3预览 / 下载
  • 默认展示「全部」文件；分类 Tab 由导入文件夹名动态生成，切换 Tab 显示对应分类文件并实时展示数量。
  • 搜索框按「文件名称 / 所属部门」模糊匹配，与分类 Tab 筛选可叠加。
  • 「预览」新标签页打开在线预览；「下载」直接保存原 PDF。

4.4 文件初始化与更新流程（运维侧）

1规划分类文件夹→ 2运行导入脚本→ 3生成编号/分类→ 4入口展示/更新
  • 组织目录：运维在源目录下按「分类」建子文件夹，文件夹名即分类名，PDF 放入对应文件夹。
  • 运行脚本：执行可复用导入脚本（含 --sys / --src / --mode 参数），导入后该系统「标准文件」入口展示。
  • 更新：后续新增、替换、下架均重新运行同一脚本；同编号文件覆盖，删除源文件即下架。
  • 下架后数量归零：若某系统文件被全部下架（数量归 0），其菜单入口随之不展示。

4.5 角色权限

角色对应系统菜单入口文件列表
供应商端用户UBK可见（有文件时）可预览、可下载
门店端用户CSP可见（有文件时）可预览、可下载
内部运营员工UOM可见（有文件时）可预览、可下载
运维 / 管理员三系统可见可预览、可下载、可导入

功能需求

Functional Requirements

5.1 顶部菜单入口「标准文件」

功能概述：在三个系统顶部菜单栏「操作指南」下拉菜单中新增统一的「标准文件」入口，进入对应系统的文件列表页。

  • 入口名称：统一为「标准文件」（带 NEW 角标），位于「集团制度」分组下。
  • 入口是否展示由该系统文件数量决定（见 5.3）。
  • 点击后新标签页打开 group-document-center.html?sys={系统标识}。

5.2 文件列表页

功能概述：展示该系统已导入的标准文件，支持分类筛选、搜索、预览与下载。页面标题统一为「{系统名}标准文件」。

5.2.1 分类 Tab 页签

功能概述：分类不预先硬编码，而是自动读取导入文件夹名称动态生成。

  • 运维在源目录下按分类建子文件夹，每个子文件夹名即一个分类（如「制度与规范」「财务结算」「服务与安全」）。
  • 系统自动读取文件夹名，生成「全部」+ 各分类 Tab，每个 Tab 右侧以角标展示该分类文件数量。
  • 分类数量由实际导入的文件夹数决定，非固定值；新增 / 删除文件夹即新增 / 移除对应 Tab。

5.2.2 文件卡片

展示字段（4 列网格，响应式收缩至 3~2 列）：

字段说明
文件名称「文件编号 + 文件名」合并为一个字段，编号在前，二者同字号、同色、加粗
文件编号企业标准编号，格式 Q/UTOUR A123BC 2026
分类标签彩色标签，标识文件所属分类（= 对应文件夹名）
发布日期 / 文件大小发布（更新）日期；大小如「18.0 KB」
操作「预览」与「下载」两个按钮

5.2.3 文件编号规则

组成部分取值说明
前缀Q/UTOUR（企业标准代号，固定）
序列首字母1 位大写字母（A-Z，排除易混淆字符）
顺序号3 位数字（100–899）
校验字母2 位大写字母
年份发布年份（如 2026）

示例：Q/UTOUR J489JR 2026，系统内唯一。

5.2.4 在线预览

点击「预览」新标签页打开独立预览页（file-preview.html），内嵌 PDF 查看，含返回、文件信息与下载；不支持内嵌时提供「在新窗口打开」兜底。

5.2.5 下载

点击「下载」直接下载原 PDF 文件，文件名与展示名一致。

5.2.6 搜索

顶部搜索框按「文件名称 / 所属部门」模糊匹配，实时过滤，可与分类 Tab 叠加。

5.3 菜单入口展示规则

功能概述：菜单入口的可见性由该系统文件数量动态决定。

  • 后端按 sys_code 统计该系统文件数量并下发。
  • 数量 > 0：展示「标准文件」入口。
  • 数量 = 0：不展示入口，用户不可见。

前置条件：运维已按系统完成文件导入（见 5.4），否则入口不展示。

5.4 文件导入与更新（运维侧）

功能概述：文件列表页不提供前端上传功能，文件初始化与更新均由运维 / 管理员通过可复用导入脚本完成。

  • 提供可复用导入脚本，参数含目标系统 --sys、源文件夹 --src、模式 --mode（init 全量 / incre 增量）。
  • 脚本可复用：后续每次调整（新增、替换、下架）重新运行同一脚本即可，无需二次开发。
  • 脚本遍历源目录下的「分类子文件夹」，文件夹名写入分类字段，PDF 写入 file_document；同名 / 同编号匹配覆盖，源文件删除即下架。
  • 可重复执行：脚本可被多次运行，已存在的文件会被识别并跳过或覆盖，不会产生重复记录。
项目说明
导入方式可复用脚本批量导入（.pdf 文件 + 分类文件夹结构）
脚本参数--sys（目标系统）/ --src（源文件夹）/ --mode（init / incre）
分类来源导入文件夹名（子文件夹名 = 分类名）
更新规则新增 / 覆盖 / 下架，按文件编号或文件名匹配
编号生成导入时按编号规则自动分配，系统内唯一
导入权限仅运维 / 管理员，普通用户只读
联动效果导入后入口展示；数量归 0 后入口不展示

5.5 功能交互与异常处理

场景交互 / 处理
文件数为 0菜单入口不展示；直接访问列表页应显示空状态或跳转回登录页（待确认）
分类筛选无结果展示空状态占位，提示「暂无文件」
搜索无结果展示空状态占位
文件丢失 / 404预览页提示无法加载，引导「在新窗口打开」或「下载」兜底
跨系统访问列表页按 sys 参数只展示对应系统文件，不展示其他系统内容

数据需求

Data Model

7.1 集团标准文件表（file_document）

字段类型说明
file_idbigint主键，自增
file_codevarchar(32)文件编号，如 Q/UTOUR J489JR 2026，系统内唯一
file_namevarchar(128)文件名称
categoryvarchar(32)分类（= 导入文件夹名），如 制度与规范 / 财务结算 / 服务与安全
deptvarchar(64)归属部门
file_urlvarchar(256)PDF 存储路径
file_sizevarchar(16)文件大小（KB）
publish_datedate发布日期
sys_codevarchar(16)所属系统：ubk / csp / uom
created_at / updated_atdatetime创建 / 更新时间
文件数据来源：file_document 不对普通用户开放写入，所有文件按 sys_code 批量导入初始化与更新（详见 5.4）。

7.2 枚举值定义

枚举字段取值
sys_codeubk / csp / uom
category由导入文件夹名动态决定，无固定枚举（示例：制度与规范 / 财务结算 / 服务与安全）

7.3 菜单入口展示判定逻辑

系统页面加载菜单时，后端执行按系统统计：
COUNT(file_document WHERE sys_code = '{当前系统}')

若结果 > 0，则渲染「标准文件」入口；若结果 = 0，则不渲染该入口。

该判定逻辑同时适用于 UBK、CSP、UOM 三套系统，确保「未导入文件则入口不展示」的规则全局一致。
